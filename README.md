# ProgressionLESS: Bionics

**All the Progression goodness, less research.**

Overhauls bionics research, so every prosthetic, bionic, implant and organ has a place in the research tree.

The "LESS" is less research: Progression: Bionics adds up to N research projects depending on your mods. This fork groups them into at most M, such as A, B and C. Everything stays in the same era, and still needs the other research it did before.

Forked from [Progression: Bionics](https://steamcommunity.com/sharedfiles/filedetails/?id=3819707781) by ferny. Huge thanks to ferny for the original mod and all the Progression work this builds on. For a really good modpack, check out [The Progression Modpack](https://steamcommunity.com/sharedfiles/filedetails/?id=3521297585).
